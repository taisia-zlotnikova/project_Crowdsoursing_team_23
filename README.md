# Бабочки: сбор данных, разметка и независимый REVIEW

Материалы команды 23. Задача: найти взрослых бабочек на фотографиях и выделить каждую прямоугольной рамкой. Для фото без бабочек итоговый ответ — пустой список рамок.

## Начать здесь

**[Чистовая инструкция запуска](clean_annotation/README.md)** — четыре последовательных ноутбука, самостоятельный API-код и единый [config.json](clean_annotation/config.json). По умолчанию изменения на платформе отключены; создание закрытых ресурсов и платный запуск разделены.

| Ноутбук | Что делает |
|---|---|
| [01 — настройка](clean_annotation/01_setup_and_settings.ipynb) | Проекты, навыки, обучения, экзамены, цены и перекрытия |
| [02 — запуск и REVIEW](clean_annotation/02_launch_and_review.ipynb) | Запуск этапов, получение ответов, независимая проверка, допуск |
| [03 — переразметка и архив](clean_annotation/03_rework_and_audit.ipynb) | Отбор ошибок, повторный REVIEW, статистика и расходы |
| [04 — итоговый датасет](clean_annotation/04_final_dataset_and_deliverables.ipynb) | Офлайн-экспорт JSON/JSONL/CSV/COCO/YOLO и HTML |

## Датасет

[Финальные данные](exports/final_butterflies_v1/) · [HTML-галерея](exports/final_butterflies_v1/gallery.html) · [ZIP](exports/final_butterflies_v1.zip).

400 уникальных фото: **354 с бабочками, 46 без бабочек, 358 рамок**. Исходная выборка — 370 кандидатов-бабочек и 30 цветов. Пилот — 25 фото, основной пул — 375. Экзамены, обучение и контрольные задания в эти 400 не входят.

Изображения не включены в архив: ссылки, размеры и лицензии находятся в images_manifest.csv. HTML загружает изображения из интернета. Нормализованные XYWH и пиксельные XYWH указаны явно; COCO использует пиксели, YOLO — нормализованные центры.

[Материалы разметки](deliverables/annotation/) · [Архив ответов и REVIEW](deliverables/annotation_evidence.zip) · [Ссылки на пулы](deliverables/annotation/pool_inventory.csv) · [Расходы](deliverables/annotation/budget.json).

Сохранены исходные задачи/ответы и REVIEW, схемы интерфейсов, инструкции, настройки экзаменов и контроля качества, ручные решения и происхождение финальных рамок. Идентификаторы исполнителей согласованно псевдонимизированы. Токены и закрытые операционные журналы не публикуются.

Расходы отражают исторические снимки: принятые выплаты отделены от ожидающих приёмки; комиссия 40% расчётная. Это не банковская выписка. Для обновления текущих статусов выполните notebook 03 с токеном заказчика.

## Установка и проверки

```bash
python3 -m venv .venv-clean
source .venv-clean/bin/activate
pip install -r clean_annotation/requirements.txt
jupyter lab
```

```bash
python3 -m unittest discover -s clean_annotation/tests -v
python3 clean_annotation/final_export.py
```

Сам API-код и экспортёр используют стандартную библиотеку Python >=3.9. Зависимости Jupyter перечислены отдельно. Для пересборки итогового датасета из опубликованных материалов токен и старые scripts/ не требуются.
